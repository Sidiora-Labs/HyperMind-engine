# HyperMind

Долговременная память для ИИ-агентов с опорой на свидетельства: сохраняйте сведения между сессиями, продолжайте работу после перезапуска и не путайте воспоминания с полномочиями.

## Зачем нужен HyperMind?

Контекстное окно агента временно. Полезная память должна переживать завершение процесса и сохранять происхождение сведений. HyperMind — движок на Rust с локальным хранением, явным происхождением данных и интерфейсами для встраивания и постоянно работающих агентов.

- Долговечные события: зашифрованный журнал только для добавления, воспроизводимые проекции, контрольные точки и восстановление.
- Прослеживаемое извлечение: лексический поиск, необязательные эмбеддинги, убеждения с учётом времени, оспаривания и ссылки на источники.
- Ограниченная активация: релевантный контекст в пределах бюджета токенов с маркировкой недоверенной памяти.
- Наблюдаемое продолжение работы: намерения, прогнозы, исходы, отложенные уведомления в тихие часы и подтверждённые процедуры.
- Несколько интерфейсов: MCP stdio, демон через Unix-сокет, аутентифицированные gRPC/REST и исходники SDK.

## Как связаны компоненты

```text
MCP / CLI / SDK / gRPC / REST
              |
       actor + capability
              |
     append-only event ledger
              |
     projections + indexes
              |
  recall -> activation -> safe rendering
```

Журнал — источник истины; проекции и индексы производны. Сохранение утверждения не подтверждает его истинность. Активация выдаёт контекст со свидетельствами, а не исполняемые инструкции. [Архитектура](docs/concepts/architecture.md) · [Модель полномочий](docs/concepts/authority.md)

## Сборка и установка из исходников

Нужны Unix-система, Git, rustup и нативные инструменты C/C++: компилятор, компоновщик, make, CMake, Perl и pkg-config. Репозиторий фиксирует Rust 1.93.0. Сборка получает зависимости Rust и компилятор protobuf; для загрузок требуется сеть.

```sh
git clone https://github.com/Sidiora-Labs/HyperMind-engine.git
cd HyperMind-engine
rustup toolchain install 1.93.0 --profile minimal
cargo build --locked -p hm-cli -p hm-mcp
cargo install --path crates/hm-cli --locked
cargo install --path crates/hm-mcp --locked
```

Эти команды устанавливают текущую копию исходников, а не опубликованные пакеты. Добавьте каталог исполняемых файлов Cargo в PATH клиента. Лексический режим по умолчанию не требует моделей или ключа провайдера. [Руководство по установке](docs/start/quickstart.md)

## Подключение клиента MCP

После установки создайте приватное состояние и зарегистрируйте stdio-сервер. Пример из двух команд для Claude Code:

```sh
hm init --path .hypermind --json
claude mcp add hypermind -- hm-mcp --config .hypermind/hypermind.conf
```

Для других клиентов задайте аналогичную конфигурацию MCP. Используйте абсолютный путь к конфигурации и убедитесь, что клиент находит `hm-mcp`:

```json
{
  "mcpServers": {
    "hypermind": {
      "command": "hm-mcp",
      "args": ["--config", "/absolute/path/.hypermind/hypermind.conf"]
    }
  }
}
```

Вызовите `remember` с `{"conversation":"demo","kind":"user","content":"The region is eu-central-1."}`, затем `recall` с `{"mode":"lexical","query":"region","limit":5}`. [Каталог 14 инструментов](docs/reference/generated/tools.md) включает remember, recall, activate, believe, retract, dispute, intend, bind, predict, outcome, attest, consolidate, inspect и forget.

На каталог актора допускается только один процесс-владелец: MCP, демон или встроенный движок, без параллельных писателей. Созданная конфигурация содержит ключи и токены полномочий актора/администратора; храните её приватно и не добавляйте в Git.

## Работа с демоном и CLI

Сначала остановите владельца MCP. Запустите демон в одном терминале:

```sh
hm serve --config .hypermind/hypermind.conf --json
```

В другом терминале сохраните воспоминание, получите идентификаторы журнала и запросите пакет контекста:

```sh
hm remember --config .hypermind/hypermind.conf --conversation demo \
  --content "The deployment region is eu-central-1." --json
hm recall --config .hypermind/hypermind.conf --query "deployment region" --json
hm activate --config .hypermind/hypermind.conf --conversation demo \
  --query "deployment region" --budget-tokens 1024 --json
```

Сейчас `recall` демона возвращает `lsns`, а не оформленный ответ; `activate` — пакет HMA1 в base64. Для чтения текста используйте MCP или рендерер SDK. `--embedded` допустим как альтернатива только после остановки демона. [Контракты CLI](docs/reference/cli.md)

## Удалённый доступ требует взаимного TLS

Удалённые слушатели включаются явно. Нужны сертификат и ключ сервера, доверенный центр сертификации клиентов и действующий токен полномочий у клиента. Команда заменяет локальный демон; указанные сертификаты необходимо подготовить:

```sh
hm serve --config .hypermind/hypermind.conf \
  --grpc-bind 127.0.0.1:7443 --rest-bind 127.0.0.1:8443 \
  --tls-cert /secure/server.pem --tls-key /secure/server.key \
  --tls-client-ca /secure/client-ca.pem --json
```

Разделяйте слушатели актора и администратора: сертификат клиента сам по себе не даёт полномочий актора. См. [удалённое развёртывание](docs/guides/deployment.md), [протокол](docs/reference/protocol.md) и [Docker, Compose, systemd, Helm](deploy/README.md). Наличие опубликованного образа не подразумевается.

## Точки входа SDK

SDK находятся в этом репозитории. Публикация пакетов и межъязыковая квалификация выполняются отдельно; исходники не означают наличия пакетов npm/PyPI или готовых бинарников.

| Язык | Исходники | Точки входа |
| --- | --- | --- |
| Rust | [hm-serve](crates/hm-serve/src/embedded.rs) | `HyperMind::open`, `session`, `remember`, `recall`, `activate`, `render` |
| TypeScript | [sdk/typescript](sdk/typescript) | `@hypermind/client`: `Client.connect`; `engine`, `render`, `migrate` |
| Python | [sdk/python](sdk/python) | `Engine.open`, `session`, `remember`, `recall`, `activate`, `render`; `Client` (mTLS) |
| Go | [sdk/go](sdk/go) | `centra/core/cortexclient`: `Dial`, `Session`, `Remember`, `Recall`, `Activate` |

Для одного актора выберите встроенного владельца или клиент демона, но не оба варианта. Python требует 3.10+, Go указывает 1.25.0. Скрипты TypeScript находятся в его workspace. См. [руководство SDK](docs/reference/sdks.md) и [каталог API из исходников](docs/reference/generated/sdk-api.md).

## Необязательные провайдеры через Centra

Локальная лексическая память работает без внешнего провайдера. В окружении процесса-владельца включайте только нужные функции; этот пример явно включает все три пути:

```sh
export CENTRA_GATEWAY_URL="https://gateway.centra.ag/v1"
export CENTRA_GATEWAY_API_KEY="<your-secret-key>"
export HM_EMBEDDING_PROVIDER=centra
export HM_RECONSTRUCTION_PROVIDER=centra
export HM_CONSOLIDATION_PROVIDER=centra
```

Эмбеддинги используют `openrouter/openai/text-embedding-3-large`. Реконструкция и консолидация используют **`openrouter/openai/gpt-5.6-luna` через `CENTRA_GATEWAY_URL`**. Эти настройки не меняют отдельную конфигурацию бенчмарков. Исторические записи тестов не являются новыми вызовами.

Не коммитьте реальные ключи и не помещайте их в JSON MCP. Провайдеру передаются выбранные данные, вызовы могут стоить денег: заранее разрешите передачу и задайте бюджет. Загрузка моделей необязательна и сама по себе не включает локальный ONNX-инференс. [Конфигурация](docs/reference/config.md)

## Свидетельства, полномочия и ограничения

- Извлечённая память — недоверенные данные, не системные инструкции, инструкции разработчика или разрешение действовать.
- Утверждения, аттестации, наблюдаемые результаты инструментов и производные процедуры сохраняют разные роли свидетельств.
- Тихие часы и политика внимания регулируют продолжение работы; прогноз не доказывает наступление исхода.
- Шифрование журнала не означает шифрования всех проекций, экспортов, логов и буферов SDK. Защищайте весь каталог состояния.
- Важен единственный писатель. Это не распределённая многопишущая БД и не хранилище секретов.
- Проверяйте `ok`, `health`, `gaps` и происхождение; успешная передача не гарантирует полноты или правильности памяти.

Перед публикацией сервиса или импортом недоверенной истории прочитайте [модель угроз](docs/security/threat-model.md).

## Бенчмарки: цели — не результаты

Спецификация задаёт следующие критерии приёмки:

| Проверка | Цель, не измеренный результат |
| --- | --- |
| LongMemEval | 500 вопросов; точность ≥ 0,90 |
| LoCoMo | Полное покрытие; неадверсариальный F1 ≥ 0,75 |
| Recall@10 | ≥ 0,95 на 10 тыс. записей |
| Прогретая активация | p99 < 10 мс на 100 тыс. записей |

Полный локальный прогон LongMemEval дал **459/500 (91,8%)** с Luna через Centra и только лексическим поиском. LoCoMo выполняется; его квалификация ещё не завершена. Реальный целевой сценарий slice-7 также прошёл. Эти результаты не подтверждают прохождение размещённого CI или готовность релиза. См. [измеренный статус и свидетельства](docs/evaluation/results.md) и [методику](docs/evaluation/methodology.md).

## Разработка и проверка документации

Из корня репозитория запускайте целевой сценарий и проверки ниже. Для документации дополнительно нужны Node.js и mdBook:

```sh
cargo test -p hm-sim --test slice7_journey
node docs/tools/catalog.mjs --write
cargo run -p hm-eval -- docs-gate
mdbook build docs
```

Каталог строится по реальным публичным интерфейсам исходников. `docs-gate` отклоняет устаревшее покрытие и битые локальные ссылки, но не сертифицирует текст или внешние URL. Следуйте [AGENTS.md](AGENTS.md) и [спецификации задач](spec/hypermind-01/spec.kvx).
