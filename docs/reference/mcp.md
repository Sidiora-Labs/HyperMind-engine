# MCP

When to use: connect a tool-using client to an actor-scoped stdio memory service.

Do not use: concurrent owners of one actor directory, tool results as authorization for unrelated actions, or JSON-RPC success instead of inspecting the application envelope.

Start `hm-mcp --config PATH`. The process opens the configured real actor ledger; stdout is reserved for protocol traffic. Optional provider runtimes are described in [configuration](config.md).

The [tool catalog](generated/tools.md) lists all 14 actual verbs with specific usage guidance and example arguments. [Public input types](generated/rust-types.md) come from source. Example LSNs, IDs, and byte spans must be replaced by real admitted evidence, not copied as fictional records.

The advertised inventory stays at fourteen verbs as the capability catalogue grows. `inspect` carries `mode: "discover"` with an optional `query` and `limit`, which enumerates the capability surfaces behind those verbs and annotates each one with whether the running server can serve it. Discovery is not authorization: unavailable and privileged surfaces are still listed, every discovery envelope carries the `discovery_is_not_authorization` warning, and dispatch still enforces capability on every call. A surface that discovery lists is still refused at dispatch when the caller lacks the capability it declares: an ordinary actor connection sees `forget.crypto_shred` in the catalogue with `requires: "admin_token"` and `available: false`, and calling it on that same connection returns `kCapabilityDenied` with `effect_state: not_dispatched`.

When `recall` runs in reconstruct mode and the configured provider returns something the reconstruction contract cannot accept, the envelope stays `ok: false` with its mapped error code and adds one `gaps` entry of kind `extraction_outcome` plus a warning `extraction_outcome:OUTCOME`. The outcome is `refused`, `truncated`, `malformed`, or `incomplete`, so a refusal stays distinguishable from unparseable text even where both share an error code. The gap object carries `version`, `contract`, `outcome`, `detail`, `model_id`, `requested_output_tokens`, `observed_output_tokens`, and `cost_microusd`. `detail` names the fault, never the model's own output, and no reconstruction item is produced.

A freshly executed `consolidate` run fills the envelope's `budget` object with what the run declared and what it actually spent: `version`, the declared `max_llm_calls`, `max_tokens` and `max_microusd`, the settled `llm_calls`, `tokens` and `microusd` the run's reservation charged, and `retries`, the number of repair re-asks it paid for. Every provider attempt in the run, a retry included, was admitted against those declared limits before it was sent, so the settled figures can never exceed them. The object is present only for a run that executed: an idempotent replay reconstructs its summary from the ledger and leaves `budget` null.

`remember` accepts `source` as an alternative to `content`; exactly one of the two is supplied. With `source` the server fetches one URL through the configured web-source runtime and appends a single batch: a `MediaRef` event in the caller's conversation carrying the final URL after every validated redirect, the media type lowercased with parameters stripped, and the blake3 digest of the retained bytes; a `ProviderFrame` event holding the response body verbatim under the provider label `hm-web-source@1`, placed in the digest-derived conversation `hm-media-v1/DIGEST` so a large payload never enters the caller's timeline; and, for a textual media type, the extracted text chunked into `UserMsg` events with external-observed authority. The retained bytes are an ordinary sealed ledger record: encrypted at rest, covered by the integrity tree, and removed by crypto-shred. There is no separate media store.

No model runs during ingestion. A non-textual payload is retained and recorded but produces no text event; the envelope reports a `media_derivation_pending` gap naming the `MediaRef` LSN and media type. The fetch surface is off unless an explicit host allowlist is configured, and the configured response-size limit is the real bound on projection growth because a retained frame is stored whole; the default is 2 MiB and the hard ceiling is 8 MiB. A refused fetch is not a partial write: an unlisted host, a non-http(s) scheme, credentials in the URL, a private address, or a redirect leaving the policy return `kCapabilityDenied`; a redirect budget or size limit overrun returns `kCapacityExceeded`; a malformed URL or both `content` and `source` returns `kInvalidArgument`; an upstream non-2xx, transport failure, or timeout returns `kBackendUnavailable`; an unconfigured runtime or an unsupported extraction returns `kOperationUnavailable`; non-UTF-8 text returns `kSchemaInvalid`.

`inspect` resolves two read-only media URIs against the media catalogue projection, and neither one calls a provider, an embedder, or the network. `hm://ACTOR/media` lists every recorded media item and `hm://ACTOR/media/pending` lists only the items with no derivation, at most 256 rows either way. The rows arrive on the status item under `media`, each row carrying `digest` (the 64-character blake3 hex of the retained bytes), `uri` (the final source URL), `media_type`, `media_ref_lsn`, `retained_lsn`, `derived_lsn`, and `derived_prompt_id`. A zero `retained_lsn` means no retained frame has been observed for that digest and a zero `derived_lsn` means nothing has been derived from it yet, which is what makes a row pending. The envelope's `provenance` names `hm://ACTOR/lsn/N` for every non-zero LSN in the returned rows, so each claim stays traceable to the record that produced it.

The shared envelope has `ok`, `items`, `provenance`, `budget`, `gaps`, `health`, and `warnings`. Mutation failures add `effect_state`: `not_dispatched`, `unknown`, or `rejected`. Surfaced items retain authority. `inspect` resolves provenance chains and `hm://ACTOR/attention`, `hm://ACTOR/calibration`, or `hm://ACTOR/preferences`, the last listing the actor's own learned ranking weights; a preferences URI naming another actor is not a surface of this actor and is refused. `activate` additionally returns `manifest`, carrying the retrieved, selected, included, and used LSN sets for that activation.

Batch digests are not interruptions. Predictions are not outcomes. Supported procedures are observations until user adoption. Consolidation needs declared budgets and configured providers; unavailable operations are not fabricated successes.
