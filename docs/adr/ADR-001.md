# ADR-001 — The ledger is authoritative

Status: accepted design, implemented incrementally.

Context: durable memory must survive crashes and explain every derived value.

Decision: append versioned events to the encrypted ledger. Projections, indexes, caches, and generations must be reproducible from a ledger prefix; they are not independent write authorities.

Consequences: migrations and background learning append events, and replay/checkpoint correctness is part of qualification. Direct cache edits cannot repair missing evidence.

When to use: introduce a new memory mutation or rebuild a read model.

Do not use: an index-only write or in-place historical overwrite as a shortcut. See [architecture](../concepts/architecture.md).
