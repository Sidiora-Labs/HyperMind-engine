# ADR-005 — Commit ciphertext and verify independently

Status: accepted integrity design.

Context: auditors should verify log integrity without decryption keys.

Decision: commit sealed frame bytes and metadata to a Merkle Mountain Range, sign checkpoints, and return append receipts. Encryption associated data binds actor, user, LSN, and kind.

Consequences: key rotation can rewrap keys without rewriting history. A separately trusted checkpoint key is needed for authenticity; verification does not establish the truth of an original observation.

When to use: audit a retained prefix, rotate wrapping material, or evaluate tampering.

Do not use: a key supplied only by the potentially compromised store as an independent trust anchor. See [MMR](../internals/mmr.md).
