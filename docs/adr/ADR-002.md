# ADR-002 — Deliver vertical slices

Status: accepted workflow.

Context: isolated layers can look complete while no user journey works.

Decision: each wave includes the schema, ledger/projection behavior, consumer, surface, restart journey, evaluation, and documentation it needs. Dependency gates qualify integration, not merely compilation.

Consequences: parallel implementation can be explicitly authorized, but incomplete dependencies remain visible and cannot be declared done. Release qualification is separate from a focused build check.

When to use: plan a capability or decide whether a task meets its acceptance criteria.

Do not use: a partial implementation or green mocked path as a completed wave. See [results](../evaluation/results.md).
