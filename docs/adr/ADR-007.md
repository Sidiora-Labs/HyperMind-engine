# ADR-007 — Publish retractable generations

Status: accepted consolidation design.

Context: background learning must be undoable without corrupting previously usable memory.

Decision: stage derived records under a run/generation, validate frozen citations, and publish by compare-and-swap only after projections are complete. Retraction immediately overrides leased views and restores the parent generation.

Consequences: runs record budgets, prompt/model identity, progress, and independent evidence. Physical cleanup is separate from logical rollback.

When to use: NREM/REM learning and replay-safe publication.

Do not use: direct memory rewrites or cleanup completion as a prerequisite for retraction. See [generations](../internals/generations.md).
