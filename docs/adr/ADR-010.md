# ADR-010 — Qualify measured behavior, not feature presence

Status: accepted evaluation policy.

Context: model judges, incomplete coverage, synthetic cohorts, and provider fixtures can produce misleading green reports.

Decision: retain dataset/model/prompt/encoder identity, coverage, exact cached responses, cost basis, and separate judge-free/judged metrics. Missing required evidence fails. Source-derived documentation catalogs and local-link validation detect interface drift.

Consequences: selected diagnostics and manual reviews explain failures but do not replace full benchmark gates. Alias identity is not an immutable model snapshot. Cross-architecture, packaging, and hosted-CI claims require their own evidence.

When to use: make quality or release claims and change thresholds.

Do not use: targets as results, ignored failures as passes, or budget resets to bypass authorization. See [evaluation methodology](../evaluation/methodology.md).
