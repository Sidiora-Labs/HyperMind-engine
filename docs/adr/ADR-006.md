# ADR-006 — Bound the foreground path

Status: accepted latency/safety design.

Context: memory should not block every agent turn on background model work.

Decision: activation reads projections/indexes, preserves required tiers, enforces token/deadline limits, and reports degraded fallback explicitly. Document embedding and consolidation stay outside the foreground path; explicit reconstruction is a separate operation.

Consequences: missing semantic coverage, stale bundles, dropped optional content, and unresolved bindings are visible. Latency claims require workload-specific measurement.

When to use: build retrieval lanes and bundle consumers.

Do not use: hidden provider calls, silent fallback, or unmeasured thresholds. See [retrieval](../concepts/retrieval.md).
