# ADR-003 — Preserve evidence authority

Status: accepted design.

Context: model-written memory can otherwise be laundered into proof of an external effect.

Decision: assign authority from source kind, preserve provenance, and admit outcome/done evidence only from observed/runtime records. Protect identity, preference, and constraint changes from automated overwrite.

Consequences: callers must retain real source LSNs and accept rejected citations. Derivation normally lowers authority; summaries do not complete work.

When to use: ingest observations, close loops, assess predictions, or derive beliefs.

Do not use: source labels as permission to act or as proof of universal truth. See [authority](../concepts/authority.md).
