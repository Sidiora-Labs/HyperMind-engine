# ADR-009 — Earn procedures from independent episodes

Status: accepted learning design.

Context: repeated model narratives are not independent evidence of a reliable strategy.

Decision: mine linked ToolCall→ToolResult→Effect→Outcome chains from closed loops. Supported status requires three independent roots across two conversations. Only user-authorized adoption turns a procedure into an instruction.

Consequences: tentative/supported procedures render as observations with support and counterexample evidence. Prediction assessment uses fixed predicates and observed LSNs, not post-hoc narrative success criteria.

When to use: learn from executed operations and report expectations honestly.

Do not use: duplicated summaries as support or support as automatic adoption. See [anticipation](../concepts/anticipation.md).
